# Library-App

A C++ **console-based library management system** built using **Object-Oriented Programming (OOP)** principles.  
The application allows managing books, users, and borrowing operations, with data stored in CSV files.

**Live Demo (Web UI)**:  
https://muharabi.github.io/Library-App/

---

## Features

- Add, remove, and display books
- Manage library users
- Borrow and return books
- Persistent data storage using CSV files
- Modular design using OOP concepts:
  - Classes
  - Encapsulation
  - Abstraction
- Simple and clear console interaction

---

## Technologies Used

- **C++**
- **Object-Oriented Programming**
- **File Handling (CSV)**
- **HTML / CSS / JavaScript** (for the web-based interface/demo)
